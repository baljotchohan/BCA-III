Option 1: Claude Desktop (One-Click JSON Config)

Add to ~/Library/Application Support/Claude/claude_desktop_config.json: 

{
  "mcpServers": {
    "bca3-hub": {
      "url": "https://bca-iii.vercel.app/api/mcp"
    }
  }
}

Option 2: Claude Web & Mobile (Custom Connectors)

  1. Open Claude.ai → Settings → Connectors.
  2. Click Add custom connector.
  3. Paste server URL: https://bca-iii.vercel.app/api/mcp.

https://bca-iii.vercel.app/api/mcp
